# 60house

> A modern short-form real estate marketplace built for the next generation of property discovery.

60house reimagines how people discover homes by combining full-screen vertical walkthroughs, intelligent recommendations, and a premium mobile-first experience.

Instead of scrolling through static listings, users explore properties through immersive video walkthroughs, personalized discovery, and seamless interactions.

---

## Features

### Marketplace
- Vertical swipe property feed
- Video and image-based listings
- Dynamic discovery engine
- Personalized recommendations
- Saved homes
- Recently viewed properties
- Flexible search and filtering

### Property Management
- Host dashboard
- Publish new listings
- Edit existing listings
- Archive and restore properties
- Property analytics foundation

### User Experience
- Full-screen immersive browsing
- Motion system with Reanimated
- Haptic feedback
- Skeleton loading states
- Transaction confirmation overlays
- Discovery end screen
- Empty state system

### Performance
- Lazy media loading
- Image prefetching
- Recommendation caching
- Profile caching
- Optimized media decoder lifecycle
- Context render optimization
